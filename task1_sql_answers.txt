Q1: How much is each member borrowing?
SQL Query:
SELECT m.member_id, m.first_name, m.last_name, COUNT(c.checkout_id) as total_checkouts
FROM members m
LEFT JOIN checkouts c ON m.member_id = c.member_id
GROUP BY m.member_id;

Reasoning: 
I use the LEFT JOIN so we don't lose members who haven't borrowed anything yet

Question 3: What are the most popular books?
SQL Query:
SELECT b.title, COUNT(c.checkout_id) as checkouts
FROM checkouts c
JOIN books b ON c.book_id = b.book_id
GROUP BY b.book_id
ORDER BY checkouts DESC
LIMIT 5;

Reasoning: 
I join the checkouts and books tables, groupby book_id to count how much times each book was borrowed, and sorting the results in descending order to easily get the top 5.

Question 4: Who are the most active readers?
SQL Query:
SELECT m.first_name, m.last_name, COUNT(c.checkout_id) as checkouts
FROM checkouts c 
JOIN members m ON c.member_id = m.member_id
GROUP BY m.member_id 
ORDER BY checkouts DESC 
LIMIT 10;

Reasoning: 
I join the members table groupby member_id to get the checkout count per person,and simpliy it to get top 10 only

Question 5: What does a neighborhood's activity look like further back in time?
SQL Query & Python Code:
SELECT c.*, m.neighborhood
FROM checkouts c
JOIN members m ON c.member_id = m.member_id
WHERE m.neighborhood = 'Maadi'
ORDER BY c.checkout_date DESC;

Reasoning: 
I used SQL to filter for the 'Maadi' neighborhood and sort the dates so the newest ones appear first. Then I just use Pandas slicing ".iloc[10:]"  to takr the first 10 checkouts.
